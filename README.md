# Arduino Uno Fundamentals

Code and examples for the free, self-paced **Arduino Uno Fundamentals** course from [eARgle Innovation Labs](https://earglelabs.com).

The course is free to enrol in at [earglelabs.com](https://earglelabs.com). Work through the lessons there, pass the five module quizzes, then build and submit your own capstone project to earn the certificate. This repository holds every sketch demonstrated in the lessons so you can read, run and modify them.

## Getting set up

| Step | What to do |
| --- | --- |
| 1 | Install the [Arduino IDE](https://www.arduino.cc/en/software) |
| 2 | Download this repository as a ZIP, or clone it |
| 3 | Open the `.ino` file for the lesson you are on and upload it to your Arduino Uno |
| 4 | Change things, break things, and compare against the wiring notes in each folder |

## Layout

One folder per module, each containing the sketch, a wiring note and the components used.

| Module | Topic |
| --- | --- |
| 01 | Getting started, the board, and your first upload |
| 02 | Digital input and output |
| 03 | Analog input and sensors |
| 04 | Serial communication |
| 05 | Putting it together |

## Hardware you need

An Arduino Uno, a USB cable, a breadboard, jumper wires, LEDs, resistors, pushbuttons and a potentiometer. Kits are available from the [eARgle store](https://earglelabs.com).
